# Frontend Portfolio Projects

Подборка учебных и тренировочных проектов для портфолио начинающего фронтенд-разработчика. Все проекты — адаптивная и семантичная вёрстка, чистые HTML/CSS, часть с базовым JS.

## Проекты в репозитории

- **Sedona (главная + каталог)** — pixel-perfect вёрстка по макету. Две страницы, точное соответствие дизайну, Flexbox/Grid, медиазапросы.
- **Article Preview Card** — интерактивный компонент превью статьи. Базовая логика на JS (переключение состояний, обработка событий), CSS-переходы.
- **Reviews Grid Section** — секция отзывов на CSS Grid: контролируемые отступы, hover-эффекты, семантика.
- **Features Grid Section** — сетка из 4 карточек функций: единый стиль, Flexbox/Grid, пропорции и отступы.
- **Recipe Landing Page** — лендинг рецепта: удобная типографика, чёткие блоки (ингредиенты, шаги), читаемость на мобильных.
- **Social Links Profile Main** — карточка профиля с соцссылками: адаптивная сетка иконок, состояния hover/focus, поддержка клавиатурной навигации, Flexbox.

## Стек

- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, медиазапросы, CSS-переменные)
- JavaScript (базовые события и логика в отдельных компонентах)
